# 健康追蹤小幫手

長輩友善的 Flutter 健康追蹤 App。

## 功能

- 個人基本資料：年齡、性別、身高、體重，儲存在本機
- 健康記錄：血壓、心率、體重、血糖、飲水、心情與備註
- 數值留意提醒，並清楚說明不代表醫療診斷
- 語音或文字症狀輸入、一般就醫科別導引與語音回答
- 播放最新健康摘要
- 歷史紀錄查看、刪除
- 趨勢圖表、最新值、平均、最高、最低與前後差異
- 大字、大按鈕與高對比的長輩友善介面

## 網頁版

`main` 分支透過 GitHub Actions 部署至 GitHub Pages：
https://111534114.github.io/Health-tracking/

資料儲存在各裝置的瀏覽器，不會自動跨裝置同步。語音功能需允許麥克風與語音辨識權限。
